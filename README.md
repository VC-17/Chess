# ♟️ Multiplayer Chess Game

A real-time multiplayer chess game built as a **browser-based application** using Node.js, Express, Socket.IO, Chess.js, EJS, and Tailwind CSS.

## 🎮 Features

- Real-time multiplayer gameplay
- Drag-and-drop chess pieces
- Real-time move synchronization using Socket.IO
- Legal move validation with Chess.js
- Pawn promotion
- Checkmate and draw detection
- Winner announcement

## 🛠️ Tech Stack

- **Node.js & Express.js** — Backend and server
- **Socket.IO** — Real-time communication
- **Chess.js** — Chess logic and move validation
- **EJS** — Templating
- **Tailwind CSS** — Styling
- **JavaScript, HTML & CSS** — Frontend

## 🚀 Run Locally

```bash

cd Chess
npm install
node app.js
